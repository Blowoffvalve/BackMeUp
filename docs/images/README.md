# Screenshots to take

The README's Open Anyway guide uses these pictures. None exist yet. They must be real screenshots, taken by a person on a **clean install of macOS 15 Sequoia or later** that has never opened BackMeUp, using a release zip downloaded from GitHub Releases with a browser (so the app is quarantined, as it is for a real user).

How to take them:

- Use the default light appearance and the default accent colour.
- Capture a window or a region (Shift-Command-4, then Space for a window), not the whole screen, so the pictures stay readable when scaled down.
- Save as PNG with exactly the filename below, in this folder.
- **Nothing personal may show:** no real name or account picture, Wi-Fi name, other apps' names, hostnames, Mac name, volume names or file names other than BackMeUp's. Use a test account with a generic name, or crop.
- Write down the macOS version used (Apple menu → About This Mac) in the table's last column.

| File | What it should show | macOS version |
|---|---|---|
| `open-anyway-1-open.png` | The Applications folder in Finder, with BackMeUp selected, ready to double-click. | 15 or later: _fill in_ |
| `open-anyway-2-done.png` | The warning that appears after double-clicking: BackMeUp was not opened because Apple could not check it, with the **Done** and **Move to Trash** buttons. | 15 or later: _fill in_ |
| `open-anyway-3-system-settings.png` | The Apple menu open, with **System Settings…** highlighted. | 15 or later: _fill in_ |
| `open-anyway-4-privacy-security.png` | System Settings with **Privacy & Security** selected in the sidebar, scrolled down to the **Security** section, showing the line that BackMeUp was blocked and the **Open Anyway** button. | 15 or later: _fill in_ |
| `open-anyway-5-open-anyway.png` | What appears after clicking **Open Anyway**: the box asking whether to open BackMeUp, with its **Open Anyway** button. If this macOS version shows no such box, capture the **Open Anyway** button in Privacy & Security close up instead. | 15 or later: _fill in_ |
| `open-anyway-6-password.png` | The box asking for the login password (or Touch ID) to allow it, with the password field empty. | 15 or later: _fill in_ |

While taking them, check that the README's steps match what macOS does, in the same order. In particular, check whether the password box comes before or after the box in step 5, and fix the README's wording if it differs.
